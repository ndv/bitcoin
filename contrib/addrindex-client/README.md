Address Index Client
---------------------

Install the dependencies

``` bash
pip3 install numpy pyopencl
```

OpenCL is used to mine the DoS-protected request; numpy provides buffers to the OpenCL kernel.

Run
``` bash
python3 query.py --host 95.31.215.177 --check-address bc1qrcq5634zjwf0va8dsrvy22qvjamzl6pusxy383 
```
